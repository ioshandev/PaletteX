# PaletteX — Color Studio

Responsive color palette generator and personal color workspace.

## Run
Extract the ZIP while keeping the folder structure, then open `index.html` in a modern browser. For best results on Android, use a local static server or an editor preview that serves the folder (some file previewers do not load linked CSS/JS files).

## Features
- Responsive dashboard with desktop sidebar and mobile drawer
- Bento-style color studio layout inspired by the supplied references
- Generate color palettes with complementary, analogous, triadic and monochromatic harmony
- Lock individual colors while generating
- Copy HEX, RGB and HSL values
- Save, use and remove palettes with LocalStorage
- Explore and trending preset palettes
- Export CSS variables
- Light and dark themes
- Custom SVG favicon and app icon

No backend, account, API key or build step required.
